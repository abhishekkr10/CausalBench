# Motion and effects prompt

Add a restrained motion system without changing information architecture.
Workspace entrances: 180–240 ms opacity, 4–6 px movement and subtle blur-to-sharp.
Hover: 120–160 ms, maximum 1.02 scale without neighboring layout shifts.
Press: around .98 scale, followed by actual loading/success/error feedback.
Dialogs: 200–260 ms opacity and .98-to-1 scale, soft background backdrop blur.
Use clear detail disclosure transitions and predictable focus.

Keep replay values discrete at recorded events. Animate selection feedback,
not fabricated intermediate measurements. Chart zoom must retain axes/units,
provide zoom level and reset, and never modify evidence. Give errors persistent
feedback; use short transitions for notifications. Document trigger, duration,
easing and reduced-motion alternative for each effect.

Keep settled text, axes and plotted values sharp. Avoid perpetual decoration,
flashing, exaggerated scaling or delayed controls. Respect both system and saved
reduced-motion settings, disabling movement, zoom animations and blur effects.
